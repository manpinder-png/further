# Domain instructions

Backend owns identity, validation, authorization, safe errors, idempotency and persistence. Never trust client actor IDs, scores, room history or facilitator context. Use revocable account sessions for real learners. Synthetic persona identities are available only under explicit local-profile development mode; never let that mode select real accounts. App compute remains loopback/local; --aws uses the authorized shared Aurora/Cognito/S3 development deployment. Authorize membership before inference. Replayed requests must not repeat paid calls or progress. Shared facilitator receives only participant-approved shared content.

Cognito is the AWS-mode identity provider. Verify JWT issuer, purpose, expiry and client audience, then map the stable subject to the app account. Hosted Facebook login uses code/PKCE, state and nonce, and stays unavailable until genuine Facebook Login credentials are configured. Never read Secrets Manager values into logs or model context. Google remains dormant in local mode. Only dedicated OAuth callbacks allow cross-site GET after local-host and state checks; all other routes keep the standard origin guard. Never link accounts based on email alone. No tokens or passwords may appear in API output or logs. See docs/AUTHENTICATION.md.
