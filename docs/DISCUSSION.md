# Further: team discussion

**Draft v0.1, October 27, 2026.** A discussion guide, not a delivery backlog. Read [Business requirements](BUSINESS_REQUIREMENTS.md) and use the [three slides](FURTHER_DISCUSSION_SLIDES.html) for the meeting.

## Shared starting point

Further is a real-time social brain connecting people and live opportunities around current learning intent. It owns inference and matching. A dedicated interface and an AI host connector are access routes. Learners may continue using their preferred AI for learning itself.

The hackathon's core evidence must be genuine: changing participant state, meaningful Meta inference, recommendations reacting to updates, and a real human connection. Supporting infrastructure can be narrow and disclosed.
