Further · Hackathon scope discussion

A real live loop with a narrow scope

Proposed proof by November 4

  1. Two people express compatible interests
  2. Meta inference informs a useful match
  3. Both choose to join and interact
  4. A real change updates the other client's result

Evidence: freshness, response time, successful connection, tested workload and limits.

Team decisions before technical design

First users and connection: which learning scenario, match criteria, and shared interaction?

Demo boundary: dedicated UI first? Does a verified connector or live event justify a scope tradeoff?

Trust and service: consent, visibility, acceptable wait, and freshness?
