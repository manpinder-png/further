## Workstreams to claim

- Product/demo: select one learning scenario, acceptance criteria, user feedback, final story.
- Experience: goal refinement, availability, match acceptance, accessible room UI.
- Matching/rooms: real presence, atomic match, room membership, shared communication.
- AI/evaluation: real Meta calls, prompt/schema evaluation, latency/cost, explain-back rubric.

The team has not assigned these to named people yet. Keep one accountable owner on each issue and use PR review across workstreams.

## Definition of done

- Two real people can complete the claimed flow, not just fixture clicks.
- A Meta model performs a meaningful, demonstrated role.
- The before/after understanding check uses a stated rubric; no fabricated outcomes.
- Failure paths are understandable: no match, disconnect, timeout, invalid model output.
- Public code contains no secrets or private onboarding notes.
- Setup and tests work from a fresh clone.
- A live demo link and accessible three-minute video are ready.
- Newly built contributions and all actual team members are clearly identified.
- Team resolves the software license before final submission.
